## 設置場所の決め方

- **校舎の端から端まで散らす**と滞在時間が伸び、混雑も分散します。
- 階段の前後、出口付近など**人が滞留すると危ない場所は避ける**。撮影のために立ち止まる人が出ます。
- 1か所あたり、掲示できる壁や机があるか現地で確認します。
- 初期設定は6か所です。数を変えると、達成条件（コンプリート）と進捗表示に自動で反映されます。

管理画面の「設置場所・QRコード」で、名称・場所（階・教室）・設置位置の案内・表示順・公開／非公開を登録します。

| 項目               | 入る内容                               | 上限      |
| ------------------ | -------------------------------------- | --------- |
| 名称               | 参加者に見えるスポット名               | 60文字    |
| 場所・階・教室     | 「3階 音楽室前」など                   | 80文字    |
| 設置位置の案内     | 「入口の掲示板、右下」など             | 160文字   |
| 表示順             | 一覧の並び順                           | 0〜999    |
| スタンプのアイコン | テンプレート12種から選ぶか、画像を登録 | PNG・JPEG |

## スタンプのアイコン

参加者のスタンプ帳に並ぶ丸いアイコンです。編集画面の「スタンプのアイコン」で選びます。

- **自動**：表示順に合わせて既定のアイコンが入ります。何も選ばなければこの扱いです。
- **テンプレート**：受付・美術・理科・カフェ・音楽・ステージ・図書・写真・ゲーム・模擬店・表彰・その他の12種から選べます。
- **画像**：「画像を選ぶ」からPNGかJPEGを登録します。正方形に切り抜いて128pxに縮小し、データベースに保存します。元の画像は残りません。

画像を使うときの注意です。

- 小さな丸の中に入ります。**遠目でも分かる、輪郭のはっきりした絵**を選んでください。細い線や小さな文字はつぶれます。
- 中央を正方形に切り抜きます。端に寄った構図は切れます。
- 写真（JPEG）は背景ごと丸く切り抜かれます。背景を透明にしたいときはPNGを使ってください。
- 参加者の端末には全スポット分のアイコンが読み込まれます。画像の登録は必要な場所だけにすると、会場の電波が弱くても軽く開きます。
- 「画像を外す」でテンプレートに戻せます。

> [!注意]
> 校章や他校・企業のロゴ、人物の写真は、権利と肖像の確認が済むまで登録しないでください。参加者全員の画面に表示されます。

## QRコードの発行と印刷

1. 管理画面のスポットカードから「QRコード・印刷」を押します。
2. 印刷用の台紙が出ます。そのまま「このQRコードを印刷」でA4に印刷できます。
3. QRは常に白地に黒で出力されます。ダークテーマのままでも印刷結果は変わりません。

> [!重要]
> QRコードには署名が入っています。`RALLY_SECRET` を変更すると、印刷済みのQRが**すべて無効**になります。印刷後は開催終了まで秘密値を変えないでください。

QRの中身は `https://<公開アドレス>/s/<場所ID>/<署名>` というリンクです。スマホのカメラアプリで読み取るとこのアドレスが開き、参加者画面へ転送されて自動で押印されます。参加登録がまだの端末では、読み取った場所を覚えたまま登録画面が開き、登録が終わった時点で押印されます。

> [!注意]
> QRに入る公開アドレスは、環境変数 `RALLY_SITE_URL`（未設定なら管理画面を開いているアドレス）です。localhostやLANのアドレスで発行したQRを印刷すると、当日そのリンクが開けません。**本番の公開アドレスを決めてから印刷してください。**

`scripts/generate-qr.mjs` は初期サンプル地点専用です。管理画面で編集した地点のQRは、必ず管理画面から発行してください。

## 掲示のしかた

- 目の高さ（おおむね120〜150cm）に貼ると、しゃがまずに読み取れます。車椅子の参加者にも届く高さを選んでください。
- 直射日光と蛍光灯の映り込みを避けます。光沢のあるラミネートは反射で読み取りにくくなります。
- **同じスポットに複数枚**貼ると行列が分散します。QRは同じ内容で構いません。
- 掲示位置は管理画面の「設置位置の案内」と一致させます。参加者はその文章を見て探します。
- 風と人の接触で落ちます。養生テープで四辺を留め、予備を本部に置きます。

## 公開／非公開の扱い

- 公開中の場所だけがコンプリートの対象です。
- 非公開にすると押印対象から外れますが、過去の押印履歴は管理者が確認できます。
- **開催中に公開・非公開を切り替えると、参加者の達成状況と順位が変わります。** 開催中の変更は、スポットが使えなくなったなど本当に必要なときだけにして、本部で記録してください。

## 事前の読み取り確認

印刷した紙を実際の掲示位置に貼った状態で、参加者と同じ操作を試します。

- [ ] 端末標準のカメラアプリで読み取ると、サイトが開いて押印される
- [ ] 参加者サイトの「QRコードを読み取る」から読み取れる
- [ ] 未登録の端末で読み取ると、登録の完了後に自動で押印される
- [ ] iPhoneのSafariとAndroidのChromeの両方で読み取れる
- [ ] 照明を点けた状態・消した状態の両方で読み取れる
- [ ] 撮影済みの写真からの読み取りも通る
- [ ] 読み取り後、スタンプ帳に反映される
- [ ] 非公開のスポットを読み取ると押印されないことを確認した

詳しい検証手順は [リハーサルと実機検証](./rehearsal.md) にあります。読み取れないときは [トラブル対応](./troubleshooting.md) を参照してください。

見取り図の画像から各団体へリンクするマップは [会場マップの登録](./venue-map.md) を参照してください。
