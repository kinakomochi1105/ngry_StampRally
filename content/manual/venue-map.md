## 何ができるか

学校が普段使っている見取り図・配置図の画像を、そのまま参加者の「マップ」画面に出せます。画像の上に**枠**を描き、枠ごとに**団体（設置場所）へのリンク**を持たせられます。参加者が教室の枠をタップすると、その団体の名前・場所・混み具合・スタンプの取得状況が開きます。

マップを1つも登録していない間は、設置場所の登録内容から自動で作る簡易マップが表示されます。登録すると、そちらに切り替わります。

## 画像を用意する

- 形式は**PNGまたはJPEG**です。長辺2000pxまで縮小して保存します。
- 文字の多い見取り図は**PNG**がきれいです。写真や陰影のある図は自動的にJPEGへ切り替えて保存します。
- 元のファイルは残りません。差し替えるときは、もう一度画像を選び直します。
- 部屋名が読める解像度で書き出してください。参加者は最大320%まで拡大できますが、元の画像がつぶれていると拡大しても読めません。
- 校舎と屋外など、図が分かれているときは**マップを複数登録**します。参加者側では名前のタブで切り替わります。

## 登録の手順

1. 管理画面の「会場マップ」を開き、「マップを追加」を押します。
2. 「地図の画像を選ぶ」から画像を選びます。
3. 画像の上を**ドラッグ**して、部屋を囲む枠を描きます。描いた枠は、まだ枠のない設置場所に自動で結び付きます。
4. 位置がずれたら、**枠をそのままドラッグして移動**します。大きさは**右下の角**をつまんで変えます。枠を選んでから**矢印キー**でも動かせます（Shiftを押しながらで大きさ、Altを押しながらで大きく動きます）。
5. 右側の一覧で、枠ごとのリンク先を選び直します。スタンプのない場所（受付・トイレ・休憩所など）は「リンクなし（表示名のみ）」を選び、表示名を入れます。
6. 一覧の右にある2つの色見本で、**枠の色**（背景・枠線）と**文字の色**（番号や表示名）を変えられます。元に戻すボタンで既定の色に戻ります。
7. マップの名前（「校舎」「屋外」など）と表示順を入れ、「参加者に公開する」にチェックを入れて保存します。

枠は**画像の縦横に対する割合**で覚えます。画面の大きさが変わっても、画像を差し替えても、同じ位置に残ります。差し替えた図の縮尺が変わったときだけ、枠を描き直してください。

| 項目       | 入る内容                             | 上限            |
| ---------- | ------------------------------------ | --------------- |
| マップ名   | 参加者のタブに出る名前               | 40文字          |
| 画像       | 見取り図（PNG・JPEG）                | 長辺2000px      |
| 枠         | 1マップあたりの枠の数                | 120個           |
| 表示名     | リンクなしの枠に出る文字             | 40文字          |
| 枠の色     | 枠線と塗り（塗りは30%の透過）        | #RRGGBB         |
| 文字の色   | 番号・表示名の色                     | #RRGGBB         |
| 表示順     | マップのタブの並び順                 | 0〜999          |

> [!注意]
> 公開した画像は、参加者サイトを開ける人なら誰でも見られます。**教職員用の避難経路図や、個人名・連絡先が入った図面は使わないでください。**

## 色の決め方

既定では文化祭サイトの配色（紫系）で表示します。地図の紙面が濃い色のときや、団体ごとに色を分けたいときだけ変えてください。

- 枠の塗りは30%の透過で重なるので、**地図の文字が透けて読める**色を選びます。
- 文字の色は番号バッジと表示名に使います。枠の色が濃いときは白、淡いときは黒に近い色が読みやすくなります。
- 獲得済みのスタンプは色を変えずにチェックへ変わるため、**色だけで意味を伝えない**ようにしてください（色覚特性のある参加者のためです）。

## 当日の運用

- 会場の変更が出たときは、同じマップを編集して枠を描き直します。画像を選び直さなければ、画像はそのまま残ります。
- 一時的に隠したいときは「参加者に公開する」のチェックを外します。参加者の一覧から消え、画像も配信されなくなります。
- 紙で配るときは、参加者画面の「この地図を印刷」から印刷できます。枠と番号は印刷にも残ります。

設置場所そのものの登録は [設置場所とQRコードの設計](./spots-qr.md) を、掲示物との使い分けは [掲示物と会場案内](./signage.md) を参照してください。
