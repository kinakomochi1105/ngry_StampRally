## 言語

- 参加者画面・管理画面のUIは日本語と英語に対応しています。
- 初回はブラウザの優先言語から選び、対応がなければ日本語になります。
- 画面の Language / 言語 から手動で選べます。選択は端末のlocalStorageに保存されます。「自動 / Auto」に戻すとブラウザ設定に追従します。
- 言語を変えても登録内容とスタンプは変わりません。

**翻訳しないもの**：文化祭名、設置場所の名称と案内、独自の学年・組、ニックネーム、CSVの見出し、削除確認の入力文字、このマニュアルの本文。主催者と参加者が入力した表記をそのまま保つためです。外部の翻訳サービスへデータを送信することもありません。

> [!注意]
> 英語で参加する来場者には、**スポット名と案内が日本語のまま**であることを受付で伝えてください。必要なら掲示物側に英語を併記します（[掲示物と会場案内](./signage.md)）。

## テーマ

- 初回は端末の設定（`prefers-color-scheme`）に合わせます。
- 画面右上の太陽／月アイコンでいつでも切り替えられます。選択は端末に保存されます。
- 印刷時は白背景に切り替わり、QRは常に白地に黒で出力されます。

## 動きを減らす設定

端末の「視差効果を減らす」「アニメーションを減らす」を有効にしている参加者には、画面の動きを出しません。初回の使い方デモもその設定に従います。

## 操作のしやすさ

- ボタンは指で押せる大きさにしてあります。キーボードのTabでも操作でき、フォーカス位置が枠で分かります。
- 画面読み上げ向けに、見出し・表・ボタンのラベルを付けています。
- スタンプの状態は色だけでなく文字（獲得済み／未獲得）でも示します。

## 運営で補うこと

アプリだけでは届かない部分があります。

- **文字が読みにくい参加者**：掲示物のフォントを大きく、コントラストを高くします。
- **カメラ操作が難しい参加者**：係員が声で手順を案内します。端末を受け取って代わりに操作しないでください。
- **スマートフォンを持たない参加者**：紙の台紙を用意します（[紙の台紙と代替手段](./paper-backup.md)）。
- **日本語も英語も読めない参加者**：絵記号中心の掲示（QRの写真＋矢印）が有効です。

## 確認方法

```powershell
npm run dev          # 別ウィンドウで
node tests/i18n.mjs
```

言語判定・翻訳・未対応文字列の保持・画面のHTTP応答を検査します。テーマと動きの設定、読み上げは手で確認してください。
