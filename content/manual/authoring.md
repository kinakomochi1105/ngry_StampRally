## ページの追加

1. `content/manual/<slug>.md` を作ります。ファイル名は英小文字・数字・ハイフンだけです（このファイル名がページのURLに使う識別子になります）。
2. 先頭にメタ情報を書きます（下の書式）。
3. `node tests/manual.mjs` で検査します。
4. コミットして配信します。`/admin/wiki` の一覧に自動で並びます。URLは `/admin/wiki/<slug>` になります。

アプリの画面からページを作る機能はありません。配信先のファイルシステムは読み取り専用で、履歴を残して間違いを戻せる形にしておくためです。開発サーバーではファイルを保存するとそのまま反映され、本番では1インスタンスにつき1回だけ読み込まれます。

## メタ情報の書式

```
---
title: ページの題名
category: 当日運営
audience: 受付担当
summary: 一覧と検索結果に出る1行の要約。
updated: 2026-09-11
order: 80
tags: [受付, 復旧コード]
---
```

| 項目 | 必須 | 内容 |
| --- | --- | --- |
| `title` | 必須 | 一覧と見出しに出ます |
| `category` | 必須 | 左の一覧の見出し。既存の分類に合わせます |
| `audience` | 必須 | 誰が読むページか |
| `summary` | 必須 | 1行。検索結果にも出ます |
| `updated` | 必須 | `YYYY-MM-DD`。**必ず更新** |
| `order` | 必須 | 整数。並び順。分類の位置もこの値で決まります |
| `tags` | 任意 | `[a, b]` または `a, b` |

`order` は10刻みにしてあります。間に挿し込めるようにするためです。**同じ分類のページは連続した `order` にしてください。** 分類の並び順は、その分類で最初に現れるページの `order` で決まります。

> [!注意]
> メタ情報が足りない、日付の書式が違う、本文が空——このいずれかでページの読み込みが失敗し、管理画面にファイル名付きのエラーが出ます。`node tests/manual.mjs` で事前に分かります。

## 使えるMarkdown

- 見出しは `#` から `####` の4段階。`#` が本文の最上位になります。
- 箇条書きは `- 項目`、番号付きは `1. 項目`。2文字以上の字下げで入れ子になります。
- `- [ ] 項目` は印刷用のチェックボックスになります。`- [x] 項目` で済み。
- 強調は `**文字**`、斜体は `*文字*`、インラインコードはバッククォートで囲みます。
- コードブロックはバッククォート3つの行で囲みます。
- 引用は `> 文章`。`> [!重要] 文章` と書くと目立つ囲みになります。使える種別は 重要 / 注意 / 参考 / 手順 の4つ。
- 表は縦棒で区切った行を並べ、2行目を区切り（ハイフンだけのセル）にします。`:---:` で中央、`---:` で右寄せ。
- 他のページへのリンクは `[文字](./slug.md)`。外部リンクは `https://` で始める通常の記法で、別タブで開きます。
- `---` だけの行は区切り線になります。

使えないもの：HTMLタグ（そのまま文字として表示されます）、画像、脚注、定義リスト、見出しの自動番号。表のセルの中に縦棒そのものを書くこともできません（別の言い方に直してください）。

## 書くときの約束

- **当日その場で読む人**を想定します。結論を先に、手順は番号付きで。
- 禁止事項は理由を添えます。理由のない禁止は破られます。
- アプリの限界は正直に書きます（「防げません」と書く）。読んだ人が運用で補えます。
- 暗証番号・パスワード・トークンの**実際の値は書きません**。
- 仕様を変更したら、コードと同じコミットでこのwikiも直します。

## 検査

```powershell
node tests/manual.mjs
```

メタ情報、ファイル名、`order` の重複、ページ間リンクの行き先、Markdownの変換（エスケープを含む）を検査します。サーバーは不要です。

## 仕組み

| ファイル | 役割 |
| --- | --- |
| `content/manual/*.md` | 本文 |
| `lib/markdown.ts` | Markdown → HTML（エスケープしてから変換） |
| `lib/manual.ts` | 読み込み、メタ情報の検査、検索 |
| `app/api/admin/manual/route.ts` | 管理者認証つきの配信 |
| `components/admin-wiki.tsx` | 画面（入口・本文・検索） |
| `app/admin/wiki/page.tsx` | `/admin/wiki`（入口） |
| `app/admin/wiki/[slug]/page.tsx` | `/admin/wiki/<slug>`（本文） |
| `app/admin/wiki/wiki.css` | この画面だけのスタイル |
| `next.config.ts` | `content/manual` を配信物に含める設定 |

Markdownは外部ライブラリを使わず、`lib/markdown.ts` が原稿を**先に全部エスケープしてから**対応する記法だけをタグに変換します。そのため本文にHTMLを書いても文字として表示されます。ページをフォルダーごと移動した場合は `next.config.ts` の設定も直してください。
